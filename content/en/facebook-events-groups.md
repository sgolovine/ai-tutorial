**What you'll get from this page:** a click-by-click way to create one clean, public **online Facebook Event** for CONAFROEDU 2026, a ready-to-paste Portuguese event description, a discussion plan from now until after the congress, and a respectful method for sharing the congress in Brazilian education **Groups** (NEABIs, teachers, postgraduate programs) — including the exact permission message to send moderators.

> [!IMPORTANT]
> We could not find an official CONAFROEDU Facebook Event as of 21 October 2026. Before creating one, ask the committee whether someone already did — **two competing Events confuse people**. If one exists, use the checklists below to fix it.

## What a Facebook Event is — and what it isn't

| A Facebook Event **is** | A Facebook Event **is not** |
|---|---|
| A stable public listing with dates, description and updates | A registration. People still register (and pay) on [Even3](https://www.even3.com.br/iconafroedu-764690/) |
| A place where people can mark **Going** or **Interested** (pt-BR: *Vou* / *Tenho interesse*) | Proof of registration — RSVPs are not ticket orders ([Meta help](https://www.facebook.com/help/317897961560790/)) |
| A discussion space for questions and updates | A guaranteed reminder system — notifications depend on each person's settings |
| A link you can share on the Page, in Groups and on WhatsApp | The place where the congress happens — that's the platform the committee chooses for transmission |

Important facts from Meta's help center ([Control who sees or joins your event](https://www.facebook.com/help/208747122499067/)):

- **Events hosted by a Page are public.** The privacy setting **can't be changed after the event is created**.
- You can control who posts in the event (for example, only hosts, or posts needing approval).
- Co-hosts are part of the event settings.

> [!WARNING]
> Never copy the list of people who clicked "Going" or "Interested" to message them on WhatsApp or e-mail. Offer a voluntary update channel instead (see [Instagram & WhatsApp](instagram-whatsapp.md)).

## Before you click "Create": five decisions

1. **Who hosts?** The Page chosen in the [Facebook playbook](facebook-playbook.md#step-1--decide-which-page-will-speak-for-conafroedu). The Event lives under that Page.
2. **One listing for the whole congress.** A single Event from 5 to 6 December. If you also run a promotional Live (e.g., a warm-up conversation), give it a clearly different title and link it back to the main Event.
3. **How is the congress delivered?** Confirm with the committee which platform transmits the sessions (e.g., YouTube, Zoom, Even3's area) and how registered people receive access. **Choose "Facebook Live" in the Event only if the congress actually streams on Facebook.**
4. **What time?** The Even3 page header shows **08:00–22:00 (GMT−3)** for the event. That is an overall range, not the final timetable — confirm the start and end times with the committee. The official program is due **by 25 November**.
5. **Who answers the discussion?** Name one person to check the Event daily.

## Step by step: create the online Event

Labels change and differ between phone and computer; look for the closest equivalent. A computer is easier for the first setup.

1. **Switch to the Page.** Make sure you are acting as the CONAFROEDU (or organizer) Page, not your personal profile. You need Page access that includes events ([Meta: Page access](https://www.facebook.com/help/289207354498410/)).
2. On the Page, open **Events** and click **Create event** (pt-BR: *Eventos → Criar evento*).
3. **Choose "Online"** (pt-BR: *On-line*). Facebook may then ask *how* it happens — typically an option like **Facebook Live** or an **external link**/other online option. Pick what matches reality (decision 3). If you choose an external link, use a **public page** (the Even3 page), never a private meeting link.
4. **Event name:**

   ```text
   CONAFROEDU 2026 — Congresso Nacional de Africanidades na Educação | On-line
   ```

5. **Start:** 5 December 2026, start time confirmed by the committee. **End:** 6 December 2026, end time confirmed. Check that the **time zone is Brasília** (if the menu shows a time-zone choice, select the São Paulo/Brasília option).
6. **Description:** paste the template below and fill in the brackets.
7. **Ticket / registration link:** if the form offers a ticket URL field, paste the **tagged** Even3 link:

   ```text
   https://www.even3.com.br/iconafroedu-764690/?utm_source=facebook&utm_medium=organic_social&utm_campaign=conafroedu_2026_inscricoes&utm_content=event_ticket_link
   ```

   Also keep the link in the description — the field may not show on every device.
8. **Cover image:** use a clean, readable landscape image (name, dates, "100% on-line"). Preview it on a phone; the edges may be cropped. Repeat all information in the text.
9. **Category/keywords:** if asked, choose education-related options.
10. **Co-hosts:** add only partners who **already agreed** (see below). You can do this later.
11. **Discussion settings:** choose whether anyone can post or posts need approval. For a small team, "approval" or "hosts only, with comments open" is safer against spam.
12. Click **Create/Publish**, then **open the Event as a visitor on your phone**: check dates, time zone, link and description.
13. **Share the Event on the Page**, and add the Event link to the pinned post.

> [!TIP]
> The organizers' Instagram (@congressosnacionais_online) and the WhatsApp contact can now point to **one** Facebook Event link — use the same link everywhere so all RSVPs and questions land in one place.

### Event setup checklist

- [ ] Acting as the Page; one canonical Event only
- [ ] "Online" type matches how the congress is really delivered
- [ ] Start/end dates and times confirmed; Brasília time zone
- [ ] Description filled with confirmed facts only; no `[CONFIRMAR]` left
- [ ] Tagged Even3 link in the ticket field **and** in the description
- [ ] Clear statement: "Vou/Tenho interesse" is not registration
- [ ] Accessibility info (only what's confirmed) + human contact
- [ ] No private meeting links or passwords in the public Event
- [ ] Discussion settings chosen; one person checks daily
- [ ] Previewed as a visitor on a phone; shared on the Page and in the pinned post

## Co-hosts: partners who manage, not logos

A co-host is a **management relationship**: co-hosts can help edit and the Event can appear on their Page. Use it only for real partners.

1. Get **explicit agreement** first — for example, from a NEABI/NEAB, an education graduate program (PPGE) or a confirmed partner organization.
2. Agree in writing **who may edit** dates, program and description.
3. Send the co-host invitation from the Event settings; the partner must **accept** it. An invitation is not acceptance.
4. A professor's employment at a university **does not authorize** listing that university as co-host or using its logo. Only the institution's own communication office can agree to that.

## Keep the Event alive (without flooding it)

One useful post in the Event discussion per week, plus a few around real deadlines, is enough. Ask real questions and have a person acknowledge answers.

| When | Event post (pt-BR examples) |
|---|---|
| Launch (this week) | "Boas-vindas! Aqui você encontra as novidades do CONAFROEDU. Inscrições, normas e valores: [link]. Dúvidas? Comente abaixo ou chame no WhatsApp (19) 98816-7751." |
| Until 4 Nov (authors) | "Autores: as submissões vão até 4 de novembro, [horário], horário de Brasília. Antes de enviar, confira modalidade, normas e a inscrição exigida do autor responsável: [link]." |
| 5 Nov (after closing, unless formally extended) | "Submissões encerradas — obrigado a todas as pessoas que enviaram trabalhos! As inscrições para participar seguem abertas até 6/12: [link]." |
| ~12 Nov | "Lembrete: os valores atuais valem até 15 de novembro. A partir de 16/11, entra o novo lote. Confira as categorias: [link]." |
| 20 Nov | A substantive reflection for Dia Nacional de Zumbi e da Consciência Negra (see [campaign timeline](campaign-timeline.md)) — not a sales post |
| By 25 Nov | "A programação oficial está no ar: [link]. Qual mesa você não quer perder?" |
| Week of 30 Nov | "Como acessar no dia: [passo a passo confirmado]. Teste seu acesso antes de sábado." |

| After | Thanks, certificate instructions (from 6 Dec, per the organizers' calendar), proceedings when published (target 15 Dec), feedback form |

Useful discussion prompts: *"Qual dúvida você gostaria que a mesa sobre [tema confirmado] discutisse?"* Don't tag everyone, and don't turn every thread into a poster.

## Lives connected to the Event

- **For a short public warm-up** (e.g., "Conversa de aquecimento — CONAFROEDU"), create a separate scheduled Live with a different title and post its link in the main Event.
- If you schedule through StreamYard, note that its "Facebook Live Online Event" feature **creates its own Facebook Event** ([StreamYard help](https://support.streamyard.com/hc/en-us/articles/9505910886292-Create-a-Facebook-Live-Online-Event)). Check the resulting links so you don't end up with duplicate congress listings.
- Live eligibility (60-day-old account, Page with 100 followers) and the 30-day replay limit are explained in the [Facebook playbook](facebook-playbook.md).
- **Watch Party no longer exists.** Facebook retired the native Watch Party feature in April 2021. Instead, organize a simple **viewing-and-discussion session**: with a group admin's approval, share a public watch link at an agreed time and have a facilitator lead the comments.

## Groups: participate first, promote second

Groups are where Brazilian teachers and researchers actually talk. They are also where spam is most hated. The rule is simple: **be useful, ask permission, disclose who you are**.

### Step 1 — Find candidate groups (manually)

Use Facebook search → **Groups** with terms like these (try with and without accents):

| Audience | Search terms | What to contribute |
|---|---|---|
| Basic-education teachers | `professores [estado]`, `educação infantil [estado]`, `alfabetização professores` | Classroom practice; national online access |
| Subject teachers | `professores de história`, `literatura afro-brasileira`, `ensino de ciências relações étnico-raciais` | A relevant ERER teaching example |
| Undergraduates | `pedagogia [universidade]`, `licenciatura [instituição]`, `centro acadêmico` | Student categories, chance to present work |
| Researchers | `pesquisa em educação`, `pós-graduação educação [região]` | Call for papers (until 4 Nov), methods |
| School management | `coordenação pedagógica`, `gestores escolares [estado]` | Team development, institutional participation |
| Anti-racist education | `educação antirracista`, `relações étnico-raciais`, `ERER professores`, `Lei 10.639` | A sourced resource or discussion |
| Black researchers / study nuclei | `NEABI [instituição]`, `NEAB [estado]`, `pesquisadores negros`, `africanidades` | Thematic fit, research exchange |

You can also search the web: `site:facebook.com/groups "educação antirracista"`. Hidden groups won't appear in search.

> [!NOTE]
> Some important organizations have **Pages**, not open Groups. For example, ABPN (Associação Brasileira de Pesquisadores/as Negros/as) links its Facebook Page [/abpn.org.br](https://www.facebook.com/abpn.org.br/) from [its website](https://abpn.org.br/), and NEAB UFSCar links [/neabufscar](https://www.facebook.com/neabufscar) from [its site](https://www.neab.ufscar.br/pt-br). A Page is not a place to post — contact them through their published institutional channels and ask whether they would share. None of these organizations is a confirmed CONAFROEDU partner.

One historical lead: a Facebook group called **Educação Infantil Antirracista** ([link](https://www.facebook.com/groups/2454962984725291/)) was studied in a 2020 UFRJ dissertation. Its current activity and rules were not verified — check before engaging.

### Step 2 — Vet each group (10 minutes per group)

- [ ] Open **About**, **Rules** and pinned/featured posts.
- [ ] Read the last 10–20 ordinary posts: are people actually talking? Are the dates recent?
- [ ] Does the group allow event promotion? Only on a certain day or thread?
- [ ] Does it allow **Pages** to join? (Meta: Pages can request to join groups whose admins allow Pages — [help](https://www.facebook.com/help/401492893195007).)
- [ ] Who are the admins/moderators, and is there an allowed way to contact them?
- [ ] Record everything in your tracking sheet (below).

### Step 3 — Participate in this order

1. Join (as the Page if allowed; otherwise as a real organizer with your own identity).
2. Introduce yourself honestly as part of the CONAFROEDU organizing team when relevant.
3. **Ask moderators for permission** when promotion is restricted or unclear.
4. Contribute something useful for *that* group — an answer, a resource, a discussion.
5. If allowed, explain why a specific session or the call for papers is relevant, and disclose your connection.
6. Come back to answer questions. **If moderators say no, stop.**

### Copy-paste: permission request to a moderator (pt-BR)

Send manually, one at a time, and personalize the bracketed parts — never paste the same text into dozens of groups.

```text
Olá, [nome]. Sou [seu nome], da organização do CONAFROEDU — Congresso Nacional de Africanidades na Educação, 100% on-line, nos dias 5 e 6 de dezembro. Vi a discussão do grupo sobre [tema específico]. O evento é pago (valores e regras na Even3) e as submissões de trabalhos vão até 4/11. O grupo aceita divulgação de congressos externos? Se sim, posso enviar um texto curto para avaliação da moderação e sigo o dia ou formato que vocês indicarem.
```

After 4 November, remove the submissions sentence unless the committee formally extended the deadline.

### A modest pilot, not a blast

- **Shortlist 8–12 groups; start with 3–5 strong matches.**
- One useful, approved contribution per group. At most **one promotional post per group per week, and only if the group allows it** — monthly means monthly; "no promotion" means none.
- For many groups, the best plan is: one launch post + one moderator-approved deadline update during the whole campaign.
- Spread the work across the week so someone can answer comments.
- No number of groups per day is "safe" from spam detection — the safeguard is relevance and permission.

Tracking sheet columns: `group URL · topic · allowed identity (Page/profile) · rules · permission date · approved slot · last contribution · questions received · tagged clicks · submissions/registrations`.

> [!CAUTION] Never do this
> Fake accounts; automated joining; scraped member lists; unsolicited mass DMs; the same link pasted in many groups; "up" comments to bump your post; tagging all members; reposting while approval is pending; hiding a rejected link in comments or a screenshot. Also note: since Meta removed the Groups API in 2024 ([Meta developers](https://developers.facebook.com/blog/post/2024/01/23/introducing-facebook-graph-and-marketing-api-v19/)), third-party schedulers **can't auto-post into groups** — Buffer, for example, sends you a reminder instead ([Buffer help](https://support.buffer.com/articles/connecting-and-publishing-to-your-facebook-group-with-buffer-VevqG0mHZG)). Post in groups by hand.

## Should CONAFROEDU create its own Group?

Probably **not before 6 December**. A one-off event rarely justifies a permanent group, and an unmoderated group is worse than none. Create one only if all three are true:

1. There is a **continuing purpose** — e.g., "Troca de práticas de educação antirracista — comunidade CONAFROEDU" that lives on after the congress.
2. There is a **named moderator** with time each week.
3. Enough participants are ready to ask and answer questions.

If you do create one:

- Pin a welcome post, rules on racism and harassment, rules on promotion, a weekly discussion and a resource index.
- Forbid identifiable student information (names, photos of children without authorization).
- Tell members what happens after the congress.
- Use **Admin Assist** (Facebook's automatic moderation for groups) only for simple spam/link criteria, and review its decisions ([Meta announcement](https://about.fb.com/news/2021/06/new-tools-to-help-group-admins-manage-their-communities/amp/)). Never block words like "negro" or "racismo".
- Facebook lets admins schedule posts in groups they manage ([Meta help](https://www.facebook.com/help/124331564818285/)).

If the team can't moderate, focus on the public Event and partners' existing communities instead.

## AI prompts for Events and Groups

### Draft or improve the Event description

```prompt
You are helping the organizing committee of an online academic congress in Brazil. Write in natural Brazilian Portuguese.
Rewrite the Facebook Event description below so it is clear on a phone: short paragraphs, the key dates first, one registration link.
Keep every date, price, name and condition EXACTLY as given. Do not add benefits, speakers, accessibility services or certificate rules that are not in the facts. Where information is missing, write [CONFIRMAR].
Make it explicit that clicking "Vou/Tenho interesse" on Facebook is not registration.
Facts: [paste fact sheet]. Current description: [paste].
```

### Adapt one post to a specific group's rules

```prompt
I'm part of the CONAFROEDU organizing team. Below are the rules of a Facebook group and a summary of recent conversations there.
1) Tell me whether event promotion seems allowed, restricted (day/thread/approval) or forbidden. Quote the rule.
2) If allowed, adapt my post to this group in natural pt-BR (max 120 words): start with something useful for this group's topic, disclose that I'm an organizer, mention that the event is paid, give one link.
3) If it's unclear, draft a short, polite permission request to the moderator instead.
Do not invent rules. Do not suggest workarounds to moderation.
Group rules: [paste]. Recent topics: [paste]. My base post: [paste]. Facts: [paste].
```

### Weekly discussion questions

```prompt
Suggest 6 genuine discussion questions in pt-BR for the CONAFROEDU Facebook Event, for teachers and researchers interested in Africanidades and anti-racist education (ERER). Each question must invite real experience, not yes/no answers or "comment YES" bait. Avoid asking people to share identifiable cases about children or traumatic experiences in public. Link each question to a theme from this confirmed program list only: [paste confirmed sessions].
```
