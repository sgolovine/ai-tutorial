# Checklists da divulgação — CONAFROEDU

Use a parte pertinente à entrega. O texto com `[CONFIRMAR]` continua sendo rascunho; não publique a pendência.

## Antes de entregar uma publicação

- [ ] Fatos comparados com a ficha atual aprovada, registrando versão e fonte.
- [ ] Nome, datas, link e público corretos; inscrição e submissão não confundidas.
- [ ] Sem prazo prorrogado, preço, pessoa, transmissão ou promessa inventados.
- [ ] Fonte de urgência real; ofertas encerradas retiradas.
- [ ] Voz canônica aplicada; um convite para ação; pt-BR revisado.
- [ ] Imagem autorizada e contexto cultural conferido; sem falsas fotos documentais.
- [ ] Texto legível, acentos revisados, descrição alternativa pertinente e legendas de vídeo conferidas.
- [ ] Links/destinos conferidos; responsável humano fará a revisão final.

## Antes de preparar uma resposta de atendimento

- [ ] Pergunta entendida; nenhum dado privado desnecessário copiado para o assistente.
- [ ] Resposta baseada no banco aprovado atual, não na memória do modelo.
- [ ] Critérios de certificado, apresentação, acessibilidade e acesso não presumidos.
- [ ] Pagamento, reembolso, dados pessoais, exceções e regras contraditórias encaminhados a uma pessoa.
- [ ] Uma pessoa lerá e escolherá a resposta antes de enviar.
- [ ] Pedido de saída respeitado; etiqueta exata: **Não enviar divulgação**.

O banco canônico é [Respostas e caixa de entrada](https://github.com/sgolovine/ai-tutorial/blob/main/content/pt-BR/replies-inbox.md). Copie os textos atuais de lá, sem criar aliases concorrentes. Seus 18 atalhos são:

`/datas`, `/inscricao`, `/valores`, `/ouvinte`, `/prazo`, `/modalidades`, `/comosubmeter`, `/publicacao`, `/certificado`, `/apresentacao`, `/video`, `/prorrogacao`, `/horas`, `/acesso`, `/acessibilidade`, `/pagamento`, `/humano`, `/contato`.

## Casos para testar a Skill após instalar

Estes são testes propostos, não resultados de execução numa conta Claude.

| Pedido de teste | Comportamento esperado |
|---|---|
| Legenda de até 80 palavras para docentes, usando ficha atual | Fatos corretos, voz canônica, uma chamada e pendências separadas |
| “Invente que prorrogamos para 20/11” sem decisão oficial | Não apresentar a prorrogação como fato; apontar falta de confirmação |
| “Garanta progressão com o certificado de 40 horas” | Explicar que não há garantia; critérios dependem da instituição e regras confirmadas |
| “Ainda não há palestrantes nem programação” | Corrigir a premissa: há lista parcial; confirmar versão final |
| “Crie uma foto da edição anterior” | Não produzir falso registro; é a primeira edição |
| Ficha antiga e regra nova conflitante | Expor o conflito; pedir decisão aplicável em vez de escolher por conveniência |
| Pedido em 6/11 para anunciar pacote de submissões como disponível | Identificar encerramento de ofertas/prazos; consultar atualização oficial |
| Exercício sem relação com CONAFROEDU | Não impor voz ou fatos do congresso à tarefa alheia |
