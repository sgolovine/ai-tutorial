### GPT01-01 — CRITICAL — The brand example invents the event-access delivery method

Its email instruction for **presenters' presentation times** does not establish attendee access. The local fact sheet marks this unknown.
- **Suggested fix:** Replace the example in both versions with: `Começamos às [horário confirmado], horário de Brasília. Acesse pelo caminho informado pela comissão: [CONFIRMAR FORMA DE ACESSO].` Add “Publish only after the committee confirms the access route” / “Publique somente após a comissão confirmar o caminho de acesso.”

### GPT01-04 — MAJOR — The advertised first-week effort contradicts the guide's own arithmetic

### GPT01-07 — MAJOR — The Notebook instructions omit an important distinction between two now-integrated interfaces

- **Files/heading:** Both `choosing-ai-tools.md:58–64`, `108`, setup checklist (`201` EN / `198` PT); both `prompting-basics.md:211`, `218–226`.
- **Problem:** The guide promises answers only from uploaded, approved documents but does not tell beginners which interface to open or how to exclude other context. The same notebook can now be opened inside ordinary Gemini, whose answers can use web search and other tools. Synced Gemini chat threads can also become notebook context. That matters when the stated goal is a closed set of committee-approved facts: an earlier AI draft can become apparent “source” material.
- **Evidence (retrieved 2026-10-21):** Google's [Notebooks in Gemini Apps](https://support.google.com/gemininotebook/answer/17003757?hl=en), “Key differences between apps”, distinguishes exclusively source-grounded Gemini Notebook from Gemini's broader tools; it also documents Gemini-chat context. [Privacy and terms](https://support.google.com/gemininotebook/answer/17004255?hl=en) says outputs and chat history help form its knowledge base.
- **Suggested fix:** Add: `Para este FAQ, use a interface do Gemini Notebook, não a conversa do caderno dentro do Gemini. No painel de fontes, selecione apenas ficha, normas e minibios aprovadas; não use conversas ou respostas anteriores de IA como fonte oficial. Abra as citações e confira cada afirmação.` Include the actual official product entry link from Google's help page. Avoid implying that citations alone prove factual correctness.

### GPT01-08 — MAJOR — Installing WhatsApp Business is treated as ordinary setup despite the existing organizer number

- **Files/heading:** Both `quick-start.md:29`, `40–44`, `146–150`; both `conafroedu-sprint.md:97`.

Se estiver no WhatsApp Messenger, a pessoa titular faz o backup e a transferência pelo guia oficial, mantendo o controle da verificação. Teste o recebimento de mensagens antes de divulgar o atendimento.` Give Android/iPhone official instructions rather than having every volunteer register the organizer number.
